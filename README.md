# DatalogMTL_Embedding_Experiments
This code supplements the work titled "Efficient Temporal Reasoning with Non-Temporal Engines:\\ Embedding DatalogMTL into Datalog".
It contains the datasets, programs and auxiliary code for experiments of embedding DatalogMTL in non-temporal reasoners.

This repository provides the data and programs used to perform experiments w.r.t. embedding DatalogMTL in non-temporal reasoners.
The reasoning engines used for these experiments can be consulted at
- [MeTeoR](https://github.com/wdimmy/MeTeoR)
- [Nemo](https://github.com/knowsys/nemo)
- [RDFox](https://www.oxfordsemantic.tech/)

For each engine, a script 'run_all_XXXX.ps1' is provided to execute all experiments.

In addition to the data and code, the original performance results can be found in the 'results' directory for each reasoning engine.
